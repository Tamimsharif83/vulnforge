# Disclaimer

VulnForge is intentionally vulnerable. It contains real, exploitable flaws,
including remote code execution, SQL injection, and arbitrary file read.

- Run it only on your own machine, on localhost.
- Never expose it to the internet or to a shared network.
- Never host a public running instance. Publishing the source is fine.
- Use what you learn here only against systems you own or are explicitly
  authorized to test, such as in-scope bug bounty targets.
